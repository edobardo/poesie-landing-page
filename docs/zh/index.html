03 — 开始之前

静谧中的问与答

我的诗歌保存在哪里？

完全由您自主选择：保存在您的 Google Drive、Microsoft OneDrive，或仅保存在设备本地（纯本地模式）。诗作的存放位置完全由您掌控。

其他人能看到我的草稿吗？

除非你主动分享，否则无法查看。你的笔记本只为你一人打开。

我需要注册单独的账号吗？

不需要，无需注册独立账号。您可以直接关联现有的 Google 或 Microsoft 账号进行云端同步，也可以在无账号的情况下以纯本地模式使用。

如果诗写到一半怎么办？

顺其自然就好。它会在页面上静静等待，直到你准备好继续创作。
