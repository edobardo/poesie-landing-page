01 / 書く

どんな気持ちにも、言葉がある。

思いついた瞬間を、そのまま書き留める。書くことに向き合い、好きなときに詩を見直しましょう。

  • 集中モードと執筆タイマー
  • 書き始めるための創作ヒント
  • タグと変更履歴

俳句・ソネット・カンツォーネのガイド付きテンプレートはPremium機能です。

02 / 形にして共有

言葉が、新しいかたちになる。

手元に残しても、誰かに届けても。書いた言葉の見せ方を選べます。

I.

あなたの詩を、あなたらしく。

投稿用の正方形画像やストーリー用の縦長画像を作成。スタイルを選び、詩を届けましょう。

追加スタイルと透かしの削除はPremium機能です。

II.

あなたの詩が動き出す。

タイプライター風の動画を作成。文字の速さ、最後の間、背景の音を選べます。

無料スタイルと透かし付きの動画を利用可能。独自音声はPremium機能です。

03 / あなたの詩集

Premium

あなたの詩が、一冊の本に。

書きためた詩に、居場所を。Premiumなら表紙と専用レイアウトを備えたPDF詩集を作成し、保存や共有ができます。

通常の書き出しにも対応：PDF、ePub、Markdown、HTML、TXT。

あなただけの場所。

詩集を作り、タグやお気に入りで言葉を探す。端末だけに保存するか、自分のGoogle DriveやOneDriveと同期できます。

最初の一行の前に

いくつかの答え。

アカウントなしで始められますか？

はい。ローカルモードで端末に書き始められます。クラウドアカウントは後から接続できます。

詩はどこに保存されますか？

端末に保存され、必要に応じて自分のGoogle DriveやOneDriveと同期できます。同時に有効な保存先は一つです。

画像や動画は無料で作れますか？

はい。無料スタイルとアプリの透かし付きで作成できます。Premiumでは追加スタイル、透かし削除、動画への独自音声が利用できます。

Premiumは定期購入ですか？

いいえ。Google Playでの買い切りです。価格と機能はアプリ内で確認でき、同じGoogleアカウントで購入を復元できます。

どの端末で使えますか？

PoesieはGoogle Playで配信中のAndroidアプリです。お使いの端末への対応はストアで確認できます。
