機能

俳句・ソネット・自由詩のテンプレート

Poesieは言葉だけに集中できるよう、背景に徹したクリーンなエディタを提供します。俳句、ソネット、自由詩のテンプレートを選び、集中用タイマーをセット。言葉が浮かばない時は、アプリからのヒントを頼りにできます。

エクスポート

SNSに投稿できるグラフィックカード

作品集を美しいレイアウトのPDF詩集に変換したり、ePub、Markdown、ウェブページとして出力できます。完全なプライバシーを保つため、暗号化ZIPによるフルバックアップも用意されています。

統計

年末のPoetry Wrapped

毎日の連続執筆記録を追いかけ、月ごと・年ごとの創作量を確認。一年の終わりには、あなたの成長を詩的に振り返る「Poetry Wrapped」が届きます。

03 — はじめる前に

静かに問いかける、よくある質問

私の詩はどこに保存されますか？

お好みに合わせて選択できます：ご自身のGoogleドライブ、Microsoft OneDrive、または端末内のみのローカル保存。あなたの詩の保存場所はあなた自身が決めることができます。

誰かに下書きを読まれる心配はありますか？

あなたが共有を選ばない限りありません。手帳はあなただけに開かれます。

専用のアカウントを作る必要がありますか？

いいえ、専用のアカウント作成は不要です。クラウド同期をご希望の場合はGoogleまたはMicrosoftアカウントを直接連携でき、アカウントなしで完全ローカルとして利用することも可能です。

書きかけの詩はどうすればいいですか？

そのままにしておいてください。再び書き始めるその時まで、ページの上で静かに待っています。
